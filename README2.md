## Behavioral Segmentation

**Data Analyst Portfolio Project**
Analyzing Behavioral Segmentation using Python & Tableau

**1. Business Problem**

Company wants to understand:
- Which gender have the most purchases/shopping?
- Which payment method have the most use?
- Which category have high purchases/shopping?
- What recommendations can be made to improve?

**2. Dataset**

**Column**      

invoice_no

customer_id

age

category

quantity

price

payment_method

invoice_date

shopping_mall

**3. Analysis Process**

The analysis was conducted through several stages:

**Step 1 -- Data Understanding**

- Dataset structure
- Data types
- Duplicate records
- Checking null

**Step 2 -- Data Cleaning**

- Just checking, not remove records
- Change data type

**Step 3 -- Exploratory Data Analysis**

I analyzed:
- Gender performance
- Payment Method 
- Category performance


**Step 4 -- Use Python**

- Data cleaning
- EDA
- K-Means Clustering
- Statistic Descriptive & summary
- Data visualization
- Identifying outlier
